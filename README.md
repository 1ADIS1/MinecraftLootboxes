# Minecraft Lootboxes

A minecraft website and server plugin for opening lootboxes and receiving items in-game. The website has database for users
with link to their minecraft profiles. This allows users to open lootboxes on website and receive items in-game.



https://github.com/user-attachments/assets/db4245df-86ac-4693-b5ff-f9848c061aeb



## Tools

* Java 21
* Papermc
* Run-task
* bukkit
* Hibernate
* Spring boot
* Hot reloading
